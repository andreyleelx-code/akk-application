# ИИ-помощник оценщика авто

Telegram-бот для компании по выкупу автомобилей: ведёт оценщика по чек-листу съёмки, находит видимые дефекты по фото, считает диапазон цены и собирает отчёт. **Финальное решение всегда за человеком.**

Обещание заказчику: не «ИИ, который не ошибается», а **второй взгляд, который не устаёт и не пропускает зоны**.

**Для встречи:** откройте [`demo/presentation.html`](demo/presentation.html). Там всё на одной странице: демо оценки трёх машин с отмеченными дефектами, переписка в боте, акт оценки, сводка, калькулятор стоимости, план и инструкция.

Идея, экономика, риски и план по разделам — в [docs/](docs/README.md).

## Как это работает

```
Оценщик в Telegram → фото по чек-листу
   1. Контролёр съёмки    все ракурсы? не размыто?          (код + быстрая модель)
   2. Дефектоскопы        кузов, оптика, колёса, салон, мотор (Claude, параллельно)
   3. Ремонт и цена       варианты из базы поставщиков,      (база + веб-поиск Claude
                          чего нет — ищет в интернете;        + формула)
                          цена = аналоги − ремонт
   4. Ревьюер             противоречия, неуверенность         (Claude)
   5. Человек             ✅/❌ по дефектам, замеры, утверждение цены
```

## Быстрый старт (локально, без Supabase)

Нужен Python 3.11+.

```bash
cd car-valuation
python -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -e ".[dev]"

cp .env.example .env                 # впишите TELEGRAM_BOT_TOKEN и ANTHROPIC_API_KEY
pytest                               # проверка: всё зелёное
python -m carval.bot.main            # запуск бота
```

В Telegram: `/new` → карточка машины → фото по подсказкам → отчёт.

По умолчанию `CARVAL_STORAGE=local`: фото и отчёты лежат в `data/local/`.

## Настройка под заказчика

| Что | Где |
| --- | --- |
| Ракурсы и их порядок | `config/checklist.yaml` |
| Какие дефекты искать по зонам | `config/defects.yaml` |
| Прайс ремонта | скопировать `config/repair_prices.example.csv` → `config/repair_prices.csv` |
| Цены аналогов | скопировать `config/comparables.example.csv` → `config/comparables.csv` |
| Свой цех и подрядчики (варианты ремонта, цены деталей и работ, сроки) | скопировать `config/suppliers.example.csv` → `config/suppliers.csv` |
| Поиск запчастей в интернете, если в базе пусто | `CARVAL_PARTS_WEB_SEARCH`, `CARVAL_CITY` в `.env` |
| Когда ставить «проверить вручную» | `src/carval/pipeline/decision.py` |
| Тексты промптов | `prompts/*.md` |
| Модели | `CARVAL_MODEL_MAIN`, `CARVAL_MODEL_FAST` в `.env` |

Цены в `*.example.csv` — **условные примеры** для запуска, не реальные расценки. Реальные файлы заказчика в git не попадают.

## Рабочий режим (Supabase)

1. Создать проект Supabase **в аккаунте заказчика**.
2. SQL Editor → выполнить `supabase/migrations/0001_init.sql`.
3. В `.env`: `CARVAL_STORAGE=supabase`, `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`.
4. Запустить бота на VPS (РК/СНГ — из-за персональных данных), например через `systemd` или `tmux`.
5. Вписать Telegram ID старших оценщиков в `SENIOR_APPRAISER_IDS`; каждый должен один раз нажать `/start` в боте.

## Калибровка

Положите 20–50 прошлых сделок в `data/cases/` (формат — [data/cases/README.md](data/cases/README.md)) и запустите:

```bash
python -m carval.backtest
```

Скрипт покажет, какие дефекты ИИ пропустил, что нашёл лишнего и насколько ошибся в цене. По этим расхождениям правятся промпты и прайс.
