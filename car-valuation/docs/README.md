# Документация

Источник: документ «Автоматизация оценки авто: ИИ-команда для компании по выкупу» (23.10.2026).

Главная мысль: не обещайте «ИИ, который не ошибается». Обещайте **второй взгляд, который не устаёт и не пропускает зоны**. Если пообещать безошибочность, ответственность за любой промах ляжет на вас.
