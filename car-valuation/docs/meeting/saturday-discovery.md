# Субботняя встреча: разведка, не продажа

Цель — понять процесс и цену ошибок, а не продать. Решение ничего не обещать до прогона на их старых кейсах.

## Процесс оценки

- [ ] Сколько машин оценивают в день? В пиковый день?
- [ ] Сколько оценщиков, есть ли старший, кто утверждает цену?
- [ ] Как сейчас проходит оценка по шагам? Есть ли письменный чек-лист?
- [ ] Сколько фото делают на машину, где они хранятся?
- [ ] Какие инструменты уже используют: толщиномер, OBD-сканер, проверка по VIN?

## Ошибки и их цена

- [ ] Какие дефекты пропускают чаще всего?
- [ ] Сколько стоила последняя крупная ошибка? Сколько таких в месяц?
- [ ] Как сейчас разбирают ошибки, кто за них платит?
- [ ] Что важнее: не переплатить при выкупе или не потерять клиента заниженной ценой?

## Данные

- [ ] Есть ли архив прошлых сделок с фото, оценкой и ценой продажи? В каком виде (папки, Excel, CRM)?
- [ ] Можно ли получить 20–50 кейсов для теста? Лучше с известными «промахами».
- [ ] Есть ли прайс на ремонт и запчасти?
- [ ] Откуда берут цены аналогов (kolesa.kz, своя база)?

## Организационное

- [ ] Кто принимает решение о внедрении? Кто будет главным пользователем?
- [ ] Как сотрудники отнесутся? (Подавать как защиту от ошибок, а не контроль.)
- [ ] Готовы ли завести аккаунты на себя: API-ключ, Supabase, VPS, бот?
- [ ] Есть ли требования к хранению персональных данных?

## Что попросить по итогам

1. 20–50 прошлых кейсов (фото + оценка + итог).
2. Их чек-лист осмотра и прайс ремонта.
3. Контакт старшего оценщика для разбора результатов.
