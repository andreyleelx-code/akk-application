# Демо для встречи

**Откройте `presentation.html` двойным щелчком.** Это один файл, в нём всё: суть, демо оценки на трёх машинах, переписка в Telegram, акт оценки, сводка руководству, калькулятор стоимости, план, инструкция, риски и вопросы к встрече. Работает без интернета (только шрифты без сети будут системные).

## Что в папке

| Путь | Что это |
| --- | --- |
| `presentation.html` | Единая страница для показа |
| `cars/<машина>/*.jpg` | «Фото» трёх машин с нарисованными повреждениями (условные иллюстрации) |
| `cars/<машина>/marked/*.jpg` | Те же фото с рамками и номерами дефектов: так их размечает программа (`src/carval/annotate.py`) |
| `reports/<машина>.json` | Отчёты в формате программы |
| `build.py`, `carsvg.py`, `template.html` | Исходники демо |

## Что настоящее, а что условное

- **Настоящее:** расчёт цены (`pricing.py`), рамки на фото (`annotate.py`), текст отчёта бота (`report.py`), формат данных. Всё посчитано кодом программы.
- **Условное:** машины нарисованы, дефекты и проценты уверенности придуманы, цены аналогов и прайс ремонта — примеры, сводка руководству — пример данных.

После субботы сюда можно положить реальные фото заказчика и прогнать настоящий анализ (`python -m carval.backtest`).

## Пересобрать

```bash
cd car-valuation
python demo/build.py
```

Нужен Chromium для Playwright (картинки рендерятся из SVG).
