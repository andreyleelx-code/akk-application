# n8n — оркестрация (этап после пилота)

Для прототипа и пилота n8n **не нужен**: бот (`src/carval/bot`) сам ведёт съёмку, вызывает конвейер и пишет в Supabase. Так меньше движущихся частей и проще отлаживать.

n8n стоит подключить, когда появятся интеграции вокруг бота:

| Сценарий | Триггер | Что делает |
| --- | --- | --- |
| Уведомления руководству | Новая строка в `reports` с `needs_manual_review = true` | Сообщение в общий чат / email |
| Итоги продаж | Расписание или вебхук CRM | Заполняет таблицу `outcomes` из CRM заказчика |
| Аналоги | Расписание | Обновляет таблицу `comparables` (с учётом условий площадок) |
| Отчёт недели | Каждый понедельник | Сводка из `report_accuracy` старшему оценщику |

## Установка (self-host на VPS, ~$5–10/мес)

```bash
docker run -d --name n8n --restart unless-stopped \
  -p 5678:5678 -v n8n_data:/home/node/.n8n \
  docker.n8n.io/n8nio/n8n
```

Supabase подключается встроенным узлом Supabase (URL + service_role ключ из аккаунта заказчика). Экспорт готовых сценариев кладите в эту папку как `*.json`.
