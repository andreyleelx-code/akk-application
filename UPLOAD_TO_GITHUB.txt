DIGITAL AKK — FIX БЕЛОГО ЭКРАНА / GITHUB PAGES

Почему был белый экран:
в репозиторий были загружены только файлы из корня, а папки assets/, icons/ и admin/ отсутствовали.
index.html пытался загрузить assets/user-LAD5EIO2.js, поэтому приложение не запускалось.

ЭТА ВЕРСИЯ СПЕЦИАЛЬНО СДЕЛАНА БЕЗ ПАПОК.
Все необходимые файлы лежат в одном уровне, поэтому GitHub Web Upload не потеряет assets/icons/admin.

КАК ОБНОВИТЬ:
1. Распакуйте ZIP.
2. GitHub → andreyleelx-code/akk-application → Add file → Upload files.
3. Перетащите ВСЕ файлы из распакованной папки одновременно. Не загружайте сам ZIP.
4. Внизу Commit changes.
5. Подождите обновления GitHub Pages и откройте:
   https://andreyleelx-code.github.io/akk-application/?v=3
6. Если браузер показывает старую версию: Ctrl+Shift+R. На телефоне очистите данные сайта/кэш или откройте ?v=3.
