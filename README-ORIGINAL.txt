ЛОКАЛЬНЫЙ ЗАПУСК
Windows: дважды нажать START_WINDOWS.bat.
Или в терминале из папки проекта:
  python -m http.server 8080
Затем открыть:
  http://localhost:8080/?preview

Важно: не открывайте index.html двойным щелчком через file:// — браузер блокирует часть модулей, конфигурации и PWA-функций.

ДАННЫЕ
config.json содержит публичный Supabase URL и publishable key. Секретные service-role ключи в клиентском проекте не используются и не должны добавляться.
Анкету можно открыть без подтверждения email; авторизация в личный кабинет остаётся отдельной функцией.
Сетевые функции (Supabase, внешние новости, Ticketon и другие внешние ссылки) требуют интернет.
