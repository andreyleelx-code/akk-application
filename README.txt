AKK Digital — HTML-версия 0.2.7

В архиве index.html, стили, скрипты и изображения.
Для рабочего запуска распакуйте весь архив и запустите локальный веб-сервер из этой папки: python -m http.server 8080
Откройте http://localhost:8080 в браузере. На Windows с установленным Python можно использовать START_WINDOWS.bat.
Простое открытие index.html двойным щелчком не поддерживает загрузку конфигурации и модули приложения.
Анкеты и новости требуют интернета и работающего Supabase. Отправка анкеты сохраняет настоящие данные в действующую базу.
Просмотр исходного макета без отправки данных: http://localhost:8080/?preview

Текущая афиша, исправления обновления новостей и Google-таблица в эту версию не добавлены.
