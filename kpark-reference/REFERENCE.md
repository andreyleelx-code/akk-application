# Референс: видео-заставка kpark.co (К.Парк) → для видеоредактора в Cowork

Источник: сохранённая страница kpark.co (`К.Парк`). Платформа: **Wix** (Studio, адаптивная сетка).
Всё ниже извлечено из HTML/CSS страницы, ничего не придумано, кроме блоков с пометкой **[ЗАПОЛНИТЬ]**.

---

## 0. Главный вывод

На сайте **два фоновых видео**. Поверх них в коде лежит **только текст** (3 строки на первом экране, 1 строка + картинка-полоса на втором).
**Цифр, подписей, выносок, графиков в HTML нет** → вся инфографика **вшита в сам видеофайл** (сделана при монтаже, а не на сайте).

Значит, наша схема такая же:
1. **Видеоредактор** монтирует ролик из рендеров + накладывает инфографику прямо в видео (1920×1080, mp4, без звука, бесшовный луп).
2. **Сайт** просто крутит этот ролик фоном и кладёт поверх 2–3 строки текста (шаблон: `hero-template.html`).

Исходное имя файла видео №1: **«общее ф.mov»** (aria-label в коде).

### Обрезка (когда файл скачан) — ffmpeg
```bash
# вырезать фрагмент с 00:05 длительностью 12 сек без перекодирования
ffmpeg -ss 00:00:05 -i file.mp4 -t 12 -c copy cut.mp4

# точная обрезка + подготовка под веб (H.264, без звука, faststart)
ffmpeg -ss 00:00:05 -i file.mp4 -t 12 -an -c:v libx264 -crf 23 -preset slow \
       -pix_fmt yuv420p -movflags +faststart hero.mp4

# раскадровка, чтобы разобрать инфографику по кадрам (1 кадр/сек)
ffmpeg -i file.mp4 -vf fps=1 frame_%03d.jpg
```

## 2. Технические параметры видео (из `data-video-info`)

### Видео №1 — HERO
```json
{
  "videoId": "6f3235_b58fd14355b94e32b64eeb18697cb476",
  "videoWidth": 1920, "videoHeight": 1080,
  "videoFormat": "mp4",
  "fittingType": "fill", "alignType": "center",
  "autoPlay": true, "playbackRate": 1,
  "qualities": ["360p","480p","720p","1080p"]
}
```
- Атрибуты тега: `playsinline muted loop preload="auto"` → **бесшовный луп, без звука**.
- Заполнение: `fill` / центр (аналог `object-fit: cover`).
- **Затемнение:** видео с прозрачностью **0.56** поверх **чёрного** фона (`--fill-layer-video-opacity:0.56; --bg-overlay-color: rgb(0,0,0)`) → картинка темнее на ~44%, чтобы читался белый текст.
- Высота секции: **≈ 55.6% ширины экрана** (≈ 1067px при 1920) на десктопе; на мобильном ≈ 102.6% ширины (почти квадрат).
- Максимальная ширина контента: **1920px**.

### Видео №2 — ПОРТФОЛИО
- Те же параметры: 1920×1080, mp4, autoplay, muted, **без loop** (проигрывается один раз).
- Прозрачность видео **1** (без затемнения), **рамка 4px чёрная**.
- Над видео заголовок, справа сверху — горизонтальная картинка-полоса (соотношение ≈ **6.8 : 1**, 2172×320, ширина 40.8% блока) — плашка/лента поверх видео.

## 6. ТЗ для видеоредактора (Cowork) — что собрать из наших рендеров

**Выход:** `hero.mp4`, 1920×1080, 25 или 30 fps, H.264, **без звука**, 10–20 сек, **бесшовный луп** (последний кадр ≈ первому), размер ≤ 8–10 МБ. Плюс `hero-poster.jpg` (первый кадр) и вертикальная версия `hero-mobile.mp4` 1080×1080 или 1080×1350.

**Монтаж:**
- 4–6 рендеров, по 2–4 сек на кадр.
- Медленное движение камеры по каждому рендеру (Ken Burns: зум 100→110% или панорама), без резких рывков.
- Переходы: плавный кросс-фейд 0.5–0.8 с.
- **Центральную треть кадра оставлять «спокойной»** — туда сайт положит заголовок; инфографику размещать по краям/углам.
- Без затемнения в самом видео — затемнение (56%) делает сайт.

**Инфографика внутри видео** — точное содержание оригинала из HTML не извлекается (она в пикселях ролика).
Чтобы повторить 1-в-1: скачать видео по ссылке из п.1 → раскадровка `ffmpeg -vf fps=1` → прислать кадры, и я распишу каждую плашку с таймингом.
Пока — шаблон в том же стиле (белые тонкие линии и текст Lato Light / Aboreto, монохром):

| Время | Элемент | Содержание **[ЗАПОЛНИТЬ нашими данными]** | Анимация |
|---|---|---|---|
| 0:00–0:03 | Выноска-линия от объекта на рендере к подписи | «Площадь участка — ___ га» | линия прорисовывается 0.4 с, текст проявляется |
| 0:03–0:06 | Счётчик-цифра | «___ м² озеленения» | число бежит от 0 до значения за 1 с |
| 0:06–0:09 | Маркеры зон (точка + подпись) | «Игровая зона», «Прогулочный маршрут», «Видовая точка» | точки появляются по очереди с пульсацией |
| 0:09–0:12 | Плашка-полоса снизу | «Проект: ___ · Город: ___ · Год: ___» | выезжает снизу, 0.6 с |
| 0:12–0:15 | Финал | логотип/название, возврат к первому кадру для лупа | fade |

Стиль плашек: тонкая линия 1–2px белая, полупрозрачная подложка `rgba(0,0,0,0.35)`, текст белый, капс с разрядкой 0.15–0.2em.

## 7. Код вставки на сайт

Готовый рабочий шаблон — **`hero-template.html`** (рядом с этим файлом): фоновое видео с затемнением 0.56, тексты, те же анимации и тайминги, адаптив. Заменить `hero.mp4` / `hero-poster.jpg` на наши файлы.

Минимальный фрагмент:
```html
<section class="hero">
  <video class="hero__video" autoplay muted loop playsinline preload="auto"
         poster="hero-poster.jpg">
    <source src="hero-mobile.mp4" type="video/mp4" media="(max-width: 750px)">
    <source src="hero.mp4" type="video/mp4">
  </video>
  <div class="hero__content">…тексты…</div>
</section>
<style>
.hero{position:relative;height:55.56vw;max-height:100vh;background:#000;overflow:hidden}
.hero__video{position:absolute;inset:0;width:100%;height:100%;object-fit:cover;opacity:.56}
</style>
```

**На Wix:** Раздел → Фон → Видео → загрузить `hero.mp4`, «Прозрачность видео» = 56%, цвет оверлея — чёрный; тексты — отдельными элементами с анимациями Reveal / Float In / Slide In.
