# ЗАДАЧИ ПО РАСПИСАНИЮ (5 штук)

Коворк → Запланированные задачи → Новая задача → проект «Instagram — личный бренд» → вставить текст → выставить время.
Время указано для примера — подстройте под свой часовой пояс.

---

## Задача 1. План на неделю
**Когда:** понедельник, 08:00
```
Команда: Исследователь трендов собирает «Сводку трендов» по нише из профиля бренда.
Стратег по ней и по последнему отчёту Аналитика составляет контент-план на 7 дней
(по шаблону «Контент-план»): 3–4 Reels, 2 карусели, 1 пост, сторис каждый день.
Выдай план одной таблицей и жди моего «ок» или правок.
```

## Задача 2. Производство на день
**Когда:** ежедневно, 09:00
```
Возьми из утверждённого контент-плана публикации на сегодня.
Сценарист пишет тексты/сценарии, Визуал — обложки и промпты, Редактор проверяет.
Для Reels с ИИ-двойником дай текст для вставки в HeyGen отдельным блоком.
Выдай «Пакет публикации» на каждую единицу и жди моего «ок».
После «ок» Публикатор публикует (или готовит к планировщику) в указанное время.
```

## Задача 3. Комментарии и директ
**Когда:** ежедневно, 13:00 и 20:00
```
Комьюнити-менеджер: пройди новые комментарии и сообщения в директ по навыку
instagram:qualification. Ответь на всё, что можно, голосом владельца.
Негатив, жалобы, денежные и юридические вопросы — не отвечай, перечисли мне.
В конце дай сводку: сколько ответов, что ждёт меня, частые вопросы (→ идеи контента).
```

## Задача 4. Сторис на день
**Когда:** ежедневно, 10:00
```
Подготовь 3–5 сторис на сегодня: опрос или вопрос аудитории, анонс сегодняшней публикации,
закулисье/мысль дня. Формат 9:16, текст на экране до 12 слов.
Выдай одним списком с промптами для картинок.
```

## Задача 5. Аналитика и решения
**Когда:** воскресенье, 19:00
```
Аналитик: собери статистику за неделю (если нет доступа — попроси меня прислать
скриншоты статистики Instagram). Заполни шаблон «Отчёт за неделю»:
подписчики, охват, топ-3 и худшие 3 публикации с причинами,
и 3 конкретных решения на следующую неделю. Стратег учитывает их в понедельник.
```
