# Инструкция запуска: ИИ-команда для Instagram в Коворке

Время на настройку: ~1,5–2 часа один раз. Дальше — 15–20 минут в день на утверждение.

---

## Короткие ответы на ваши вопросы

| Вопрос | Ответ |
|---|---|
| Сколько проектов заводить? | **Один.** Все агенты работают в одном проекте, чтобы видеть общий профиль бренда, план и историю. Несколько проектов = агенты «не знают» друг о друге. |
| Сколько скиллов подключить? | **8 готовых + 1 свой** (`insta-brand-team`). Минимум для старта — 5 (отмечены ★ ниже). |
| Сколько задач по расписанию? | **5** (план на неделю, производство, комментарии, аналитика, сторис). Тексты задач — в файле `04_РАСПИСАНИЕ_ЗАДАЧ.md`. |
| Куда что вставлять? | Инструкции проекта ← `01_ИНСТРУКЦИИ_ПРОЕКТА.md`; файлы проекта ← `02`, `03`, `05`, `06`; навык ← `insta-brand-team.zip`; расписание ← `04`. |

> Названия пунктов меню в Коворке могут немного отличаться от написанных здесь — ищите по смыслу («Проекты», «Навыки/Skills», «Коннекторы», «Запланированные задачи/Scheduled»).

---

## Шаг 0. Подготовка вне Коворка (30–40 мин)

1. **Instagram → профессиональный аккаунт.** Настройки → Тип аккаунта → «Автор» (рекомендую) или «Бизнес».
2. **Привязать к странице Facebook** (нужно для API и плагина): Instagram → Настройки → Центр аккаунтов → подключить Facebook и создать/выбрать страницу.
3. **ИИ-двойник** (подробно — `05_ИИ_ДВОЙНИК.md`):
   - HeyGen: создать аватар (видео 2–5 мин или 10–20 фото).
   - ElevenLabs или голос в HeyGen: записать 1–3 мин голоса.
4. **Meta Business Suite** (business.facebook.com) — бесплатный планировщик публикаций. Пригодится, если плагин не умеет постить сам.

---

## Шаг 1. Создать проект (5 мин)

1. Коворк → **Проекты → Новый проект**.
2. Название: **«Instagram — личный бренд»**.
3. В поле **Инструкции проекта** вставить весь текст из `01_ИНСТРУКЦИИ_ПРОЕКТА.md`.
4. В **Файлы проекта / Знания** загрузить:
   - `02_ПРОФИЛЬ_БРЕНДА.md` (**сначала заполнить!** — см. Шаг 4)
   - `03_КОМАНДА_АГЕНТОВ.md`
   - `05_ИИ_ДВОЙНИК.md`
   - `06_ШАБЛОНЫ.md`

---

## Шаг 2. Подключить навыки (10 мин)

Коворк → **Настройки → Навыки (Skills)** → включить:

| # | Навык | Зачем | Старт |
|---|---|---|---|
| 1 | **insta-brand-team** (свой, загрузить `insta-brand-team.zip`) | Мозг команды: роли, конвейер, правила | ★ |
| 2 | **content-navigator** | Контент-план и посты под нишу | ★ |
| 3 | **humanizer-ru** | Убирает «нейросетевой» стиль из текстов | ★ |
| 4 | **video-director** | Хуки, сценарии Reels, раскадровки | ★ |
| 5 | **image-prompt-engineer** | Обложки, карусели, фото «вас» в образах | ★ |
| 6 | **content-zavod** | Из одного материала — пачка контента | |
| 7 | **seedance-prompt-engineer** | Промпты для атмосферных B-roll видео | |
| 8 | **personal-brandbook** | Один раз — оформить брендбук | |

Как загрузить свой навык: Настройки → Навыки → **Загрузить / Upload skill** → выбрать `insta-brand-team.zip`.

---

## Шаг 3. Подключить Instagram (10 мин)

1. Коворк → **Плагины / Коннекторы** → найти **Instagram** → установить.
2. В чате проекта написать: **«Настрой Instagram»** — запустится навык `instagram:configure`, он попросит токен Graph API и проведёт по шагам.
3. Проверить, что умеет плагин:
   - отвечать на комментарии и директ — **да** (навык `instagram:qualification`);
   - публиковать посты — **уточнить** при настройке. Если не умеет — публикуем через Meta Business Suite (агенты готовят пакет: файл + подпись + время, вы за 1 минуту ставите в планировщик).
4. Дополнительно (по желанию): **Google Drive** — общая папка, куда агенты складывают готовые материалы.

---

## Шаг 4. Заполнить профиль бренда (20–30 мин) — самое важное

Откройте в проекте чат и напишите:
> «Проведи со мной интервью и заполни 02_ПРОФИЛЬ_БРЕНДА.md. Вот мой Instagram: @___»

Агент задаст вопросы по блокам. Готовый файл перезагрузите в Файлы проекта (замените старый).
Опционально: «Сделай мой персональный брендбук» (навык personal-brandbook).

---

## Шаг 5. Тестовый прогон вручную (20 мин)

В чате проекта по очереди:
1. «Стратег: составь план на 2 недели» → проверить, поправить.
2. «Сценарист: сделай 3 сценария Reels для двойника из плана» → проверить.
3. Один сценарий вставить в HeyGen → получить видео → посмотреть, нравится ли.
4. «Аналитик: проанализируй мой профиль и последние 12 публикаций».

Если всё устраивает — переходим к автоматике.

---

## Шаг 6. Включить расписание (15 мин)

Коворк → **Запланированные задачи → Новая задача** → для каждой из 5 задач из `04_РАСПИСАНИЕ_ЗАДАЧ.md`:
- выбрать проект «Instagram — личный бренд»;
- вставить текст задачи;
- поставить время.

⚠️ Если задачи Коворка выполняются на вашем компьютере — он должен быть включён и Claude запущен в это время. Проверьте это в настройках задачи.

---

## Шаг 7. Режим работы

**Недели 1–4 — «с утверждением»:**
- Каждое утро агенты кладут в чат «Пакет дня»: сценарий/пост, подпись, хэштеги, обложку, время.
- Вы отвечаете «ок» или правки → делаете видео в HeyGen (5 мин) → публикация.

**С 5-й недели — «автопилот»:** если правок почти нет, разрешите агентам публиковать текстовые/карусельные посты без утверждения; видео с двойником — всё равно глянуть перед выходом.

**Раз в неделю (воскресенье):** читаете отчёт аналитика (5 мин) и пишете: «принимаю» или что поменять.
